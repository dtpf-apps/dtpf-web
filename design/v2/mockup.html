dauth

Un sistema de autenticacion passwordless que sirve como infraestructura para todas mis aplicaciones.

El problema. Cada aplicacion que construia necesitaba su propio sistema de login. Repetia la misma logica de autenticacion, gestion de tokens, y flujos de email. Queria una solucion centralizada que pudiera reutilizar.

La solucion. dauth es un sistema de autenticacion como servicio (AuthaaS) que proporciona login sin contrasena a cualquier aplicacion. Soporta magic link y passkey (WebAuthn). Cada app conectada obtiene su propio tenant con configuracion independiente y authorization code flow.

El resultado. Actualmente gestiona la autenticacion de 4 aplicaciones en produccion. 854 tests automatizados. CI/CD completo con GitHub Actions. Monitoring centralizado con Grafana + Loki. El frontend fue rediseñado completamente con Tailwind CSS v4 eliminando Ant Design.
